Below is a catalogue of the major **configuration‑surface “domains”** that Windows exposes for programmatic inspection or modification. Think of each surface as a distinct skill that the Manager can assign to a Domain Agent for a bounded workflow task.

| #   | Configuration Surface                                             | Primary Access APIs / Interfaces                                                                                                             | Typical Data / Settings                                                                             |
| --- | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 1   | **Windows Registry**                                              | `Microsoft.Win32.Registry*` (C#), `Reg*` APIs, PowerShell `Microsoft.Win32.Registry` module                                                  | System‑wide & per‑user key/value pairs (boot options, COM registration, policies, user preferences) |
| 2   | **DCOM (Distributed COM) Configuration**                          | `DCOMCNfg.exe` UI, COM `IClassActivator`, WMI `Win32_DCOMApplication`, PowerShell `Set-ItemProperty` on `HKLM\Software\Microsoft\Ole`        | COM activation permissions, security launch/access levels, authentication settings                  |
| 3   | **WMI (Windows Management Instrumentation)**                      | `System.Management` namespace, PowerShell `Get‑WmiObject` / `Get‑CimInstance`                                                                | System hardware, OS, services, event logs, security policy objects                                  |
| 4   | **File System ACLs & Attributes**                                 | .NET `System.IO` + `System.Security.AccessControl`, PowerShell `Get‑Acl`, `icacls`                                                           | NTFS permissions, inheritance, file/folder ownership, reparse points                                |
| 5   | **Group Policy (Local & Domain)**                                 | `Microsoft.GroupPolicy` COM API, PowerShell `Get‑GPO`, `LGPO.exe`                                                                            | Registry‑based policy settings, security options, scripts, software deployment                      |
| 6   | **Windows Services**                                              | `ServiceController` class, PowerShell `Get‑Service`, `sc.exe`                                                                                | Service startup type, recovery actions, dependent services, security descriptor                     |
| 7   | **Scheduled Tasks**                                               | Task Scheduler COM API (`TaskScheduler`), PowerShell `Get‑ScheduledTask`                                                                     | Triggers, actions, credentials, run conditions                                                      |
| 8   | **Network Interface & TCP/IP Stack**                              | `NetworkInterface` class, PowerShell `Get‑NetAdapter`, `netsh`                                                                               | IP addresses, DNS, firewall rules, NIC properties                                                   |
| 9   | **Windows Firewall (Advanced Security)**                          | `INetFwPolicy2` COM interface, PowerShell `Get‑NetFirewallRule`                                                                              | Inbound/outbound rule sets, profiles, connection security rules                                     |
| 10  | **Power Settings (Power Plans)**                                  | `PowerShell Get‑PowerPlan`, `powercfg.exe`, `IPowerSettings` API                                                                             | Sleep/hibernate settings, processor throttling, display timeout                                     |
| 11  | **Security Accounts Manager (SAM) / Local Users & Groups**        | `System.DirectoryServices.AccountManagement`, PowerShell `Get‑LocalUser` / `Get‑LocalGroup`                                                  | User accounts, password policies, group memberships, SID mappings                                   |
| 12  | **Event Log Configuration**                                       | `EventLog` class, PowerShell `Get‑EventLog`, `wevtutil`                                                                                      | Log sizes, retention policies, source registration                                                  |
| 13  | **AppLocker/Executable Restrictions**                             | `AppLocker` COM API, PowerShell `Get‑AppLockerPolicy`                                                                                        | Rule collections (allow/deny) based on path, hash, publisher                                        |
| 14  | **Windows Update Settings**                                       | `Microsoft.Update` COM interface, PowerShell `Get‑WindowsUpdateLog`, registry under `HKLM\Software\Policies\Microsoft\Windows\WindowsUpdate` | Update channels, install schedules, restart behavior                                                |
| 15  | **Device Manager (PnP) Configuration**                            | `SetupAPI` (`SetupDi*`), PowerShell `Get‑PnpDevice`                                                                                          | Driver versions, device enable/disable state, device properties                                     |
| 16  | **Environment Variables (System & User)**                         | `Environment.GetEnvironmentVariable`, PowerShell `Get‑ChildItem Env:`                                                                        | Path, temp directories, custom variables                                                            |
| 17  | **Shell/Explorer Settings (Folder Options, Start Menu, Taskbar)** | Registry (`HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer`), COM `IShellFolder`, PowerShell `Get‑ItemProperty`                      | View mode, hidden files, pinned items                                                               |
| 18  | **Certificates Store**                                            | `X509Store` class, PowerShell `Get‑ChildItem Cert:`                                                                                          | Trusted root CAs, personal certificates, revocation lists                                           |
| 19  | **Hyper‑V / Virtualization Settings**                             | WMI `Msvm_*` classes, PowerShell `Get‑VM`, `Set‑VMProcessor`                                                                                 | VM configuration, virtual switches, checkpoint policies                                             |
| 20  | **Remote Desktop / RDP Settings**                                 | Registry (`HKLM\Software\Microsoft\Windows NT\CurrentVersion\Winlogon`), Group Policy, PowerShell `Get‑ItemProperty`                         | Allow connections, network‑level authentication, encryption level                                   |
| 21  | **System Boot Configuration (BCDEdit)**                           | `bcdedit.exe`, WMI `Msvm_Boot` for Hyper‑V, PowerShell `bcdedit` wrapper                                                                     | Boot manager entries, Safe Mode, hypervisor launch settings                                         |
| 22  | **Accessibility / Ease‑of‑Access Settings**                       | Registry (`HKCU\Control Panel\Accessibility`), PowerShell `Get‑ItemProperty`                                                                 | Narrator, high‑contrast, sticky keys                                                                |
| 23  | **Windows Search Indexing Options**                               | COM `ISearchCatalogManager`, PowerShell `Get‑SearchConnector`, Registry                                                                      | Indexed locations, file type filters, crawl schedule                                                |
| 24  | **Multimedia/Audio Device Settings**                              | Core Audio APIs (`MMDevice API`), PowerShell `Get‑AudioDevice` (via modules)                                                                 | Default device, volume levels, format settings                                                      |
| 25  | **Print Spooler & Printer Configuration**                         | `PrintSystemObject` classes, PowerShell `Get‑Printer`                                                                                        | Printer drivers, ports, queue settings                                                              |
